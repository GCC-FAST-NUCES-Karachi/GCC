# GitHub Campus Club FAST-NUCES

Website for GitHub Campus Club FAST-NUCES, built with Next.js and JavaScript.

## Start locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Commands

```bash
npm run lint
npm run build
npm run start
```

## Current routes

- `/` — initial GCC landing-page shell
- `/learn` — placeholder
- `/events` — placeholder
- `/team` — placeholder

The visual specification is in `docs/design.md`; current progress is in `docs/plan.md`; and the sequenced file-by-file implementation guide is in `docs/implementation-plan.md`. The current foundation deliberately uses plain JavaScript, not TypeScript.
